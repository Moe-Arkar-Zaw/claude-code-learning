## 2.

- **Anthropic connection**: Claude Code connects to Anthropic services through the internet. If connection fails, check the network, DNS, VPN, firewall, or use a stable connection. A common fix is to test with `nslookup api.anthropic.com 1.1.1.1` and verify the server response.
- **Claude Code prompting**: Good prompts should include the task, context, constraints, and the desired output format. Clear instructions help Claude give better and more accurate answers.
- **Claude .md file meaning**: A `.md` file is a Markdown file. It is used for writing notes, documentation, and project guides using headings, bullet lists, links, and code blocks for claude to instruct.
